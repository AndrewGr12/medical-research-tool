    Methodology
    • Auto suggests Median (IQR) if n < 10 or |skewness| ≥ 1; otherwise Mean (SD). Constant variables default to Mean (SD).
    • This is a heuristic for exploratory description. It is not a formal normality test or a substitute for statistical judgment; verify assumptions before formal analysis or publication.
    • SD is the sample SD (n−1). Quartiles use linear interpolation (R type 7 / Excel QUARTILE.INC). Skewness is the adjusted Fisher–Pearson coefficient (needs n ≥ 3).
    • Grouped Table 1 tests: continuous variables use Welch's t-test / Welch's ANOVA in Parametric mode or Mann–Whitney U / Kruskal–Wallis in Nonparametric mode. Categorical variables use Pearson's chi-square when no expected count is below 1 and at least 80% are 5 or greater; sparse 2×2 tables use Fisher's exact test and other sparse tables use a conditional Fisher–Freeman–Halton exact test when enumerable. Otherwise, p-values are NA with an explanation. Tests use complete observations by variable and treat groups as independent. No normality test is performed; select Nonparametric when appropriate. Categorical percentages use non-missing observations within each group. Exports prefix text cells starting with = + - @ with an apostrophe to prevent spreadsheet formula execution.
    • Missing = blank, NA, N/A, NaN, null, missing, “.” or “-”. Other non-numeric entries in a mostly numeric column are ignored in the summary and listed in a warning.
